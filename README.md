# IraCast Weather App

IraCast is a modern weather dashboard built with HTML, CSS, and JavaScript. I created this project to practice working with APIs, JavaScript, and responsive web design while building a clean weather interface.

## Features

- Search weather by city
- View current temperature and weather conditions
- Feels-like temperature
- Humidity and wind information
- Rain chance
- Sunrise time
- 5-day weather forecast
- Weather icons based on current conditions
- Fahrenheit temperature display
- Responsive design

## Built With

- HTML
- CSS
- JavaScript
- Weather API

## What I Learned

While building IraCast, I practiced fetching data from an API and using JavaScript to display the results dynamically.

I also worked on handling user searches, organizing weather data, and creating a responsive dashboard that presents information in a simple and easy-to-read way.
